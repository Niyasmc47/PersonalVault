# PersonalVault

PersonalVault is a personal information and growth management web application.
It is designed to help users manage their vault, expenses, skills, projects,
achievements, certificates, social links, and resume information in one place.

## Tech Stack

- Frontend: React, TypeScript, Vite, ESLint
- Backend: Java, Spring Boot, Maven, Spring Web, Spring Data JPA,
  Spring Security, Jakarta Validation, MySQL

## Repository Structure

- `frontend/` - React client application
- `backend/` - Spring Boot API application
- `docs/` - architecture and development documentation
